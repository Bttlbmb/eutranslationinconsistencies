# Reading the findings

Start with a law in the collection. Its card tells you which source version was reviewed, how much of the comparison is complete, and how many findings have an impact assessment. These are different measures. A review can be complete without finding a difference, and a published finding can still lack an impact rating.

Open the law to see its English text beside a list of findings. Select highlighted wording or an item in the list to compare the language versions. Each comparison preserves the original quotation, its English translation and the explanation of the possible difference in meaning. English provides a common reference; it has no higher authority than the other official versions.

## Narrow the comparison

Language and impact filters work together. The language menu lists versions with matching findings. Major and Limited select assigned binary assessments; No impact rating yet includes findings without an assigned level. This last category can include an unresolved assessment and does not imply a limited effect.

The list groups records that share an English passage and quotation. Language counts still count the original finding records, so the number of comparison groups can be smaller. The arrows move between those groups. Copy link preserves the selected comparison and filters.

Text order follows the source. Potential impact opens an issue-level view, where one issue can link several language-specific findings. A rating describes a possible change in legal outcome if a reading prevails, with its confidence and uncertainty shown separately. Earlier three-tier assessments retain their explanations as awaiting reassessment.

## Read the evidence in context

Review and sources provides the exact version, source links, archives and coverage notes. A completed label refers to the preserved source scope. Missing languages, mixed-language official files and unfinished comparisons remain explicit. A source import checks currency at that point in time; the project does not continuously monitor later legal changes.

Highlights reproduce exact substrings. When the same words occur several times, the reader can highlight several matches; this does not establish a separate discrepancy at every occurrence. The source itself is never rewritten to make a comparison clearer.

The collection's language summary compares only languages available in every fully reviewed act in its stated scope. It is a count within this collection, not a measure of overall translation quality. No finding should be read as an adjudicated legal error.

The website works while the research computer is offline. Anyone with the link can read and forward it. Search-engine exclusion is requested, but the link is not an access restriction.
